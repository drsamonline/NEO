One source. Four backends. No mystery build.

NOVA is a statically-typed compiled language. Its semantic pipeline lowers C, JavaScript, Rust and WebAssembly from the same SIR, and a parity harness proves the outputs agree.

Program shape

One file, no build system required.

fibonacci.nova
fn fibonacci(n: int) -> int {
    if n < 2 {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}

fn main() -> int {
    let i = 0;
    while i < 10 {
        print(fibonacci(i));
        i = i + 1;
    }
    return 0;
}

Build & run

Prerequisites: Rust toolchain, cc, and for parity node + wat2wasm.

Native build

  • cargo build --release
  • nova-compiler run examples/hello.nova
  • nova-compiler build examples/fibonacci.nova -o fib
  • nova-compiler emit examples/hello.nova --target wasm

What is distributed

  • Source + Cargo workspace (no binary release yet)
  • Static landing page + language docs (this site)
  • No APK or EXE artifacts are published
  • HTML is the supported web build; native binaries are built locally

Roadmap

Authoritative status lives in DEV_PLAN.md.

Done

  • Lexer, parser, semantic analyser, SIR and lowerer
  • C reference backend with ABI v3 runtime
  • JS / Rust / WASM execution for arrays, structs, tuples and closures
  • Four-backend parity harness in CI
  • Diagnostics with spans and help text in the LSP

Next

  • PWA/offline docs and faster first load (in progress here)
  • WASM float struct fields and float closure signatures
  • LSP references and go-to-definition
  • Real package registry, DWARF debugging
  • Published binaries and reproducible releases
