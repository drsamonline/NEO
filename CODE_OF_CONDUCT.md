# Code of conduct

Short, because a long one nobody reads protects nobody.

## Expected

- Assume the other person is acting in good faith and is competent. Most
  disagreements here are about a trade-off, not about competence.
- Criticise the code, the claim or the design — not the person. "This will not
  compile because X" is fine. "You clearly do not understand Rust" is not.
- Say what you did not verify. A pull request that admits "I could not run the
  Windows build" is worth more than one that implies it ran.
- Be patient with questions. This project's documentation is young, and someone
  asking how the parity harness works is doing you a favour by revealing a gap.

## Not acceptable

- Harassment, insults, or sustained disruption of a discussion.
- Demeaning comments about a person's identity, background, language, caste,
  religion, gender, disability or level of experience.
- Publishing someone's private information without their consent.
- Dismissing a report of the above, or retaliating against the person who made it.

## Scope

Issues, pull requests, commit messages, code comments, and any space where someone
is representing this project.

## Reporting

Email **sohilmomin2000@gmail.com**. Reports are read by the maintainer, kept
confidential, and answered. If the report concerns the maintainer, say so — there is
no second maintainer to route it to, and that is worth knowing before you write it.

## Consequences

Anything from a private word to a permanent ban, depending on the behaviour and
whether it continues. The aim is a project people can work in, not a process.
