# Standard-library modules whose emitted C does not compile yet.
#
# One module per line, the name first, then why. `ci.yml` fails if a module outside
# this list does not compile, and also if a module inside it starts compiling — so
# the list can only shrink. `core` and `math` are not listed, so they must keep
# compiling.

io   (1) `Option<File>` cannot exist — `Option` is one C struct with `int`, `double` and `char*` payload slots and none for a struct, so `Some(File { ... })` is assigned to `payload_i`. That is ADR 0003, not a codegen bug. (2) `NovaArray SPINNER_FRAMES = nova_array_from((int[]){...}, 4);` is a call at file scope — "initializer element is not constant". The duplicate `chdir` was removed in #51; `chdir` itself remains a name the C library also uses, which is why `core`'s copy is still a collision risk if a program imports it.
