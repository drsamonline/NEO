# Standard-library modules whose emitted C does not compile yet.
#
# One module per line, the name first, then why. One line, not one paragraph: the check
# reads the first word of every non-comment line as a module name, so a wrapped reason
# becomes nine modules that do not exist and the ratchet fails in both directions. `ci.yml`
# fails if a module outside this list does not compile, and also if a module inside it
# starts compiling — so the list can only shrink.
#
# **The list is empty.** All four modules — `core`, `io`, `math` and `text` — emit C that
# compiles. That took six defects, in this order: `[float]` arrays (ADR 0006), `[String]`
# arrays (ADR 0006), `s[i]` on a `String` (ADR 0007), `as` casts being dropped (ADR 0008),
# `if` used as a value (the chain and the type), and finally arrays of arrays (ADR 0009),
# which is what `text`'s `levenshtein` needed.
#
# An empty list is a real result and not a reason to delete the file: the check that reads
# it is what will notice the first module that stops compiling.
#
# **A module compiling is not a module working.** This gate asks only whether `cc` accepts
# the emitted C. `text` compiled while `split` was an infinite loop and while `==` on two
# `String`s compared pointers, and the gate said nothing about either. Those were found by
# running the functions, not by reading the gate. Correctness for the standard library is
# `compiler/tests/end_to_end.rs`, and it covers the functions someone thought to assert.
