# Standard-library modules whose emitted C does not compile yet.
#
# One module per line, the name first, then why. `ci.yml` fails if a module outside
# this list does not compile, and also if a module inside it starts compiling — so
# the list can only shrink. `core` and `math` are not listed, so they must keep
# compiling.
#
# Every reason below is quoted from C that `nova-compiler emit` actually produced,
# not inferred from the NOVA source.
#
io   Three defects, none of them small. (1) `Option<File>` cannot exist: the emitted Option has `int payload_i; double payload_f; char* payload_s;` and no struct payload, so `fopen`'s `Some(File { ... })` is `(Option){ .tag = 0, .payload_i = (File){ ... } }` — "incompatible types when initializing type 'int' using type 'File'". (2) `NovaArray SPINNER_FRAMES = nova_array_from((int[]){...}, 4);` is a call at file scope — "initializer element is not constant". (3) `chdir` is redefined, because a stdlib function and the C library share the name.
text text.c:540-559: the same `Option<File>` and global-initialiser defects as io, reached through `use io;`.
